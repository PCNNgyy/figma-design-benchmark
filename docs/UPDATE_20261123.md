# Framework update — 2026-11-23

Version 0.2.0 updates the portable source release while keeping all experiment and Arena runtime data separate.

- Updated the unified Claude Code inference/judging harness to `figmaeval-cvpr2027/v1`, including frozen inputs, original/copy isolation, the four-page Starter contract, complete matrix validation, independent seeded judge contexts, G0 and strict missing-score handling.
- Updated the local seed-forwarding proxy and bound score exports to the actual frozen batch configuration, seeds, Read coverage and screenshot revisions.
- Included offline Arena candidate revision and model expansion helpers. They preserve unaffected votes, annotations and progress; they do not create experiment data or connect to a production round.
- Removed fixed production model/task-count assumptions from declared captured-review manifests while retaining provenance and matrix checks. The existing anonymous UI, configurable judge identities and loopback defaults remain portable.
- Added a text/source allowlist, runtime-data ignore rules, exact Git index/tree/history checks, a preventive pre-push hook and an active offline GitHub Actions workflow with no artifact-upload step.

Validation: all 151 offline Node tests and all 24 offline Python tests pass. Both example manifests pass structural validation. The framework-only working tree and both pre-existing local commits pass the source/content checks. A local bare-remote integration test confirms that the pre-push hook rejects a runtime snapshot before its commit object reaches the remote. Synthetic CLI/provider tests establish local seed forwarding, not commercial provider enforcement or a live benchmark reproduction.

No real task dataset, designs, screenshots, inference traces, judge results, reviewer accounts, ballots, database files, credentials, internal deployment settings or historical result bundles are part of this update.
